# PetShop — Laboratório de Inovação

Projeto acadêmico de um sistema simples para organização de clientes, animais e serviços de um PetShop. Esta primeira entrega apresenta o requisito **RF-001 — Cadastro de animal de estimação**, seu caso de uso, uma arquitetura inicial, decisões arquiteturais e um protótipo HTML com CSS embutido.

## Quadro de tarefas

| A Fazer | Em andamento | Concluído |
|---|---|---|
| Editar cadastro do pet | Definir banco de dados | Identificação do RF-001 |
| Consultar pets por cliente | Planejar API | Caso de uso UC-001 |
| Agendar banho e tosa | Revisar regras | Protótipo HTML+CSS |
| Registrar serviços realizados | Preparar apresentação | Arquitetura e ADRs |

## Como visualizar o protótipo

Abra o arquivo `src/prototipos/SEMANA-01/RF-001-cadastro-pet/index.html` em um navegador. Não é necessário instalar dependências, pois o CSS está embutido no próprio arquivo.

## Como clonar

```bash
git clone https://github.com/JoaoPauloArrC/projeto-petshop.git
cd projeto-petshop
```

## Observação acadêmica

O protótipo é uma representação inicial da solução e não possui persistência real de dados. A API REST e o banco de dados estão previstos na arquitetura para as próximas etapas do projeto.
